# Content-Gap Strategy Deck Visual System

## Chosen Theme: Academic Light — Evidence Architecture

This deck uses the established Devasophy **Academic Light** system rather than a generic corporate presentation theme. The visual thesis is a research folio: parchment ground, navy structural type, amber as the decision signal, and the existing curricular section colors only when a slide names a specific learning domain. The deck should feel like an annotated strategic brief, not a marketing pitch.

| Token | Value | Deck role |
|---|---|---|
| Parchment | `#F8F5ED` | Primary canvas and negative space |
| Ink Navy | `#15233B` | Slide titles, data axes, structural rules |
| Amber | `#D69E2E` | Decisions, priority arrows, active recommendation |
| Logical Reasoning Red | `#B84030` | Logical Reasoning pillar only |
| Reading Comprehension Blue | `#1976D2` | Reading Comprehension pillar only |
| Formal Logic Gold | `#C8860A` | Formal Logic pillar only |
| Test Strategy Green | `#2E7D52` | Planning/performance pillar only |
| Quiet Gray | `#697386` | Secondary annotation, footers, caveats |

## Typography and Hierarchy

Use **Lora** for large display statements and section-divider titles; its literary seriousness supports the research-folio concept. Use **Space Grotesk** for body copy, numbers, labels, and diagrams. Use **JetBrains Mono** only for compact evidence labels, query counts, dates, and source markers. Titles should be short, declarative, and left aligned. Body content should favor 1–3 concise claims, with a visible evidence line at the bottom rather than dense citations in the main reading path.

## Layout Rules

1. All slides use a generous outer margin and a thin navy rule near the top, echoing a study notebook’s ruled page.
2. Content slides use a 7:5 asymmetric grid: the main conclusion on the left, evidence or a restrained chart on the right.
3. Section dividers use only a large statement, sequence number, and a single amber square; they contain no bullet lists.
4. The cover uses a left-aligned title block, a narrow amber spine, and a small “Strategic brief” monospaced label.
5. Recommendation slides use one large amber priority numeral plus compact action cards; never use decorative gradients.
6. Use domain color only as a chip, chart bar, or short rule. Navy remains the dominant structural color so the four section colors retain semantic meaning.
7. Keep transitions subtle and limited to opacity/position fades under 250 ms; honor reduced-motion preferences.

## Chart and Evidence Treatment

Use flat horizontal bars with direct value labels and no heavy chart boxes. The 20-query coverage chart should lead the analysis section; the competitor-appearance chart should support—not dominate—the competitor slide. Wherever an evidence figure is based on the public fallback sample, add a small gray mono caption: **“Public sample; not traffic, rank, or keyword volume.”** This preserves the report’s evidence discipline.

## Slide-Specific Direction

| Slide range | Visual treatment | Purpose |
|---|---|---|
| Cover | Parchment, amber spine, navy title | Establish calm, rigorous tone |
| 1–4: Diagnosis | Ruled folio layout and evidence bars | Show why the issue is discoverability architecture |
| 5–8: Strategy | Pillar chips and numbered action cards | Make the public-resource model concrete |
| 9–10: Product connection | Small UI-diagram framing, navy/amber | Connect public content to learner experience without app screenshots |
| 11: Measurement | Three-step path with mono evidence labels | Define honest decision signals |
| 12: Closing | Section-divider restraint with one decision sentence | Close on approval and next action |

## Accessibility Requirements

All information conveyed by domain color must also appear in labels. Amber text must use a navy or dark-ink background when contrast would otherwise be insufficient. Charts require direct labels rather than color-only legends. Maintain a minimum 18 pt body size and 30 pt title size in the rendered deck.
